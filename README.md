### 🚢 Featured: [Pierside](https://github.com/Hemi131/Pierside)

A Docker Desktop–style container UI for **Rancher Desktop**. It covers containers, Compose projects, images and volumes, live logs, an in-browser shell, file browsing, and remote engines over SSH. It also includes an MCP server, so AI assistants can work with your containers under permissions you set.

`TypeScript` · `React` · `Python` · `FastAPI` · `Docker Engine API` · `Go`
